# Internal Asset Tracker

A full-stack company asset-tracking system featuring a robust ASP.NET Core Web API backend and a responsive Angular frontend. Designed to manage equipment lifecycles, checkout transactions, audit trails, and automated email reminders for overdue returns.

## Core Features

- **Asset Management:** Manage equipment lifecycles, checkout transactions, and audit trails.
- **Authentication & Security:** JWT Bearer Auth and Role-Based Access Control (Admin, Asset Manager, Standard User).
- **Automated Reminders:** Background sweep for overdue assets and automated email notifications.
